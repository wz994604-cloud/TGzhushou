# Telegram 风格运营工作台 UI 交付记录

## 目标

这是一个运营后台工作台，主业务对象是“发布机器人下的 Telegram 会话”。布局参考官方 Telegram WebA/WebK 的三栏工作区，但只保留本项目的聊天、用户、编写、任务、记录和设置功能。

## 采用的界面模式

- **Workbench shell**：窄侧栏承载机器人切换和功能导航，会话列表与聊天区保持稳定分栏。
- **Conversation list**：头像、标题、最后消息、时间、未读数和选中态形成快速扫描层级。
- **Message workspace**：聊天标题、消息气泡、回复、附件、Emoji 和发送状态集中在主区。

刻意不复制 Telegram 的通话、联系人、新建群组等普通账号能力，也不复制官方代码或资源；仅采用公开产品的交互结构作为参考。

## 本次实现

- 桌面端改为窄机器人/功能侧栏 + 会话列表 + 聊天区。
- 机器人切换仍由现有发布机器人数据驱动，侧栏显示机器人首字母头像并保留隐藏兼容选择器。
- 会话头像优先通过 Telegram Bot API 获取并缓存 `file_id`，缺失时回退首字母头像。
- 增加 Telegram 风格浅色聊天背景、气泡、选中态、状态徽标和移动端窄栏适配。
- 保留原有业务页面、账号密码登录、消息发送和测试接口。

## 验收重点

- 桌面端：侧栏、会话列表、聊天区不互相覆盖。
- 移动端：侧栏可切换功能，选中会话后聊天区占满主区域。
- 头像加载失败不影响会话文本显示。
- 多机器人切换仍隔离会话、任务和用户数据。
