# 统一账号登录规则

适用于 Telegram 小程序。小程序使用 Railway 后端和账号数据。

## 入口和认证
- 任何 Telegram 用户都能通过 `/start`、`/login` 或菜单打开登录页，无 Telegram ID 白名单。
- 小程序使用后台账号密码登录。Telegram SDK 仅用于小程序窗口与布局适配，不作为后台身份或权限来源。
- 不开放自行注册；不生成免密码登录链接；旧链接及仅凭 Telegram 身份建立的会话不再有效。
- 登录成功保存当前端会话，沿用 24 小时有效期。过期后回到账号密码登录页。
- “退出当前账号”仅撤销当前会话，其他端或设备的独立会话不受影响。

## 权限
- 只有 `wz9946` 可以创建账号、指定账号可操作的机器人、添加或配置机器人。
- 普通账号仅操作已授权的机器人；前端隐藏操作不是授权依据，服务端继续执行原有权限校验。
- 保留环境配置中的既有账号及数据库已有账号、密码哈希和机器人授权，不新增角色系统，不改历史账号的授权范围。
- 添加账号：以 `wz9946` 登录 → 系统设置 → 管理账号 → 添加账号 → 填写账号密码并选择机器人 → 保存。

## 会话与存储兼容
- 继续使用 HttpOnly / Secure / SameSite=Lax Cookie、同源检查和现有登录失败限流。
- 复用 `browser_sessions` 表及 `tgzhushou_session` Cookie 名称，是为了兼容已保存的账号会话，不代表仍有两套登录机制。
- 旧 `browser_links` 表不会再创建或读写。现有数据库中的历史表不做破坏性删除。
- `ADMIN_TG_IDS` 不再读取；`ADMIN_LOGIN_ACCOUNTS`、`ENTRY_BOT_TOKEN`、`CONFIG_KEY` 等有效配置继续使用。

## 发布验证
检查匿名访问、小程序登录页、正确/错误密码、账号创建权限、跨机器人越权、会话过期、单会话退出、重开后的小程序会话恢复。
真实 Telegram 小程序客户端验证不由本地浏览器或 HTTP 模拟替代。


## 登录恢复与操作记录

- 登录会话有效期为 24 小时，过期后重新输入账号密码。
- 设置中的“退出当前账号”只结束当前会话；“退出所有设备”结束此账号的全部会话，不影响其他账号。
- 修改密码会结束全部会话；忘记密码时联系主账号管理员重置。
- 主账号可在账号管理中查看最近 100 条账号与机器人操作记录。
- 发送结果待核实时先检查最新消息，再决定是否重试；已发送但列表刷新失败时无需重发。
- 会话资料中的置顶、备注、手动未读和归档沿用本机存储；搜索消息查询当前机器人、当前会话的服务器历史。
