# 修复记录

## 文字链接与任务管理（2026-09-30）

- 编辑器增加「添加链接」对话框，分别填写显示文字和跳转地址；点击已有链接可修改或移除，移除后保留文字和表情。
- 已停止任务可以编辑并重新开始。定时任务从未来时间点继续，不补发过去时段；手动任务恢复草稿状态，不自动发送；过期单次任务需要先修改发布时间。
- 停止会取消该任务未发送的排队消息，不撤回已经发送的消息；正在发送的请求可能完成。
- 任务列表增加删除确认，删除任务及对应发布记录，不删除 Telegram 消息，也不删除机器人配置、目标绑定或媒体。
- 本次不备份生产数据、不变更数据库结构、环境变量或持久卷；沿用原服务发布。
- 验证：移动端文字链接编辑/保存、自定义表情保留、任务停止/恢复/删除、绑定保留和排队取消，均使用本地临时数据库及模拟 Telegram。

## 多管理员入口修复

- `/tg/entry` 的 `/start` 判断改用与小程序 API 相同的管理员列表；不再单独读取旧 `ADMIN_TG_ID`。
- 兼容已有 `ADMIN_TG_IDS` 配置，无需再次修改变量。
- 增加真实 webhook 回调的模拟测试：两位管理员收到入口按钮，非管理员不收到；同时核对小程序签名验证。
- 本地仅验证入口与身份校验，未向真实 Telegram 账号发送消息。
