# 飞机助手视觉规范

更新时间：2026-10-06。按已确认方案第九、十节整理；具体流程/验收引用[同一收尾方案](C:/Users/win11/Projects/飞机助手/.design/页面巡检_20261006/方案_全页面巡检问题与收尾修改建议.md)。本文件收录稳定的视觉角色，不重写业务流程或另建主题。

## 1. 方向与页面分区

**保留当前粉蓝底色、渐变与光带；前景采用有色玻璃，内容可读优先。** 不改冰白或参考图深蓝背景，不增加全局光晕。高级感来自层次、字级、对齐与细亮边，不来自每个按钮发光。

| 区域 | 固定规则 |
|---|---|
| 导航 | 保留功能顺序与分组；品牌、机器人身份及账号清晰。机器人切换只保留身份/头像板块入口，不在顶栏重复 |
| 顶栏 | 承载已有搜索/工具，不新增无业务用途入口；与导航同族材质 |
| 聊天 | 列表、消息、资料任务分区明确；导航/列表/资料同族浅磨砂，用细线分隔，不分别包大圆角外卡 |
| 功能页 | 统一标题、说明、主要内容及操作区；深浅层次按用途分配，不每页独立调色 |
| 内容与操作 | 阅读、编辑正文优先；独立滚动，固定操作栏不遮内容；资料/工具不足空间时收纳 |

正常宽屏结构保留，不全站硬套一组列宽。窄窗按收尾方案8.1/10.1：先资料抽屉，再导航收纳，最后列表/会话单页切换。892×668目标为列表约280px、消息占剩余空间；不把缩小字体当作响应式方案。

## 2. 中文字体与层级

字体栈：**思源黑体 → Noto Sans SC → Microsoft YaHei UI → Microsoft YaHei → sans-serif**。先检查实际加载，Figma与浏览器字体回退可能不同；CSS声明不是字体已加载的证明。保留已有合格字体，不临时引入装饰英文或花体。

| 位置 | 字号 | 字重 | 行高 |
|---|---:|---:|---:|
| 品牌标题 | 18px | 600 | 24px |
| 页面标题 | 20px | 600 | 28px |
| 卡片标题 | 16px | 600 | 24px |
| 导航 | 15px | 500；选中600 | 22px |
| 正文、输入、表格值 | 14px | 400 | 22px |
| 字段标签 | 14px | 600 | 22px |
| 按钮 | 14px | 600 | 20px |
| 时间、ID、次说明 | 12px | 400 | 18px |

同角色统一，不要求全站一个字号。长昵称/任务标题常规或500字重，不整表粗体。正文不增加明显字距；标题最多轻微0.01–0.02em。数字可用同字体等宽数字，不换成另一种字体。功能文案保持中文，必要机器人用户名/ID/协议名保留原值。

## 3. 板块与文字颜色

以下是**前景参考值**，不是背景新配色；优先保留已合格Token，用Variables和Styles复用。实际模糊/叠层会影响合成，不宣称单一色值必然达到参考图效果。

| 表面 | 用途与参考 | 文字 |
|---|---|---|
| 浅磨砂 | 导航/列表/资料；蓝灰透光基底 `rgba(105,143,191,.22)` | 主 `#172f50`；次 `#425c79` |
| 深玻璃 | 功能外面板；`rgba(35,60,99,.68)` 配低强度同族渐变 | 主 `#f1f7ff`；次 `#d7e5f6` |
| 内层 | 表头/目标条目/次操作；参考 `rgba(134,182,237,.18)` 与细分隔线 | 随所在深浅面，不全站强制白字 |
| 阅读/输入层 | 凝实淡蓝 `rgba(224,237,250,.94)`；不留突兀硬白块 | 深字；占位参考 `#425c79` |

- 外层透、内层弱分隔、正文凝实；不全部深蓝，也不全部透明。
- 表头与次按钮融入所在面板，避免硬白横条；编辑器工具图标按底色保持清楚。
- 普通文字合成对比度目标4.5:1；至少24px常规或约18.7px粗体可按大字3:1。测亮光带经过的最不利区域，不能只测原始Token。
- 阅读不清时调整前景承载/文字，不换背景。缺模糊支持时用同色系凝实回退层。

## 4. 按钮、输入与状态

| 控件 | 规则 |
|---|---|
| 主按钮 | 沿用当前主色和已有尺寸；14px/600，不新增发光。主要动作清晰，不把所有按钮都做主按钮 |
| 次按钮 | 同面板内层、清晰边缘，跟随深浅面选择文字；不是大块硬白 |
| 危险操作 | 名称与普通动作分开，有明确危险语义；保留原确认和权限，不只依赖红色 |
| 输入 | 淡蓝凝实层、深字、清楚占位与聚焦边；placeholder不替代label |
| 标签 | 按内容宽度和统一内边距，不铺满表格列；真实状态，不伪造在线/已读 |

默认、悬停、选中、聚焦、禁用、加载、空态、错误、未知按需补齐，优先复用Variants。聚焦边2px且不裁切；选中状态有边线/形状补充。真实不可操作才禁用，并说明原因；正常筛选不伪装成禁用。操作中与成功分开，失败保留内容并提供合理恢复。

已有40px高按钮优先复用；网页点击区至少36px，触控至少44px，不能靠缩点击区塞工具。聊天输入宽度不足时正文全宽第一行、工具与发送第二行；发送至少72px。具体判定及状态保留见方案8.2/10.1。

## 5. 间距、图标与细节

| 项目 | 统一档位 |
|---|---|
| 间距 | 8 / 16 / 24px；同角色对齐，不各页随意选值 |
| 圆角 | 功能外卡16px，输入/按钮10px，消息12–16px；结构栏不额外套圆角 |
| 导航条目 | 44px高，文字15px；低高度减少间距/独立滚动，不放大字填空白 |
| 头像 | 40–48px；真实头像保留，品牌和无头像占位统一深墨色，不批量黑圈 |
| 图标 | 已有线性资产优先，20–22px，约1.5–2px线宽；不混入不同风格符号 |
| 磨砂 | 18–24px模糊目标；细亮边1px，高光贴边、内阴影克制 |
| 柔影 | 参考 `0 8px 22px rgba(41,74,115,.11)`；强调层级，不每卡四周发光 |

消息按Telegram式结构：接收左、发出右，淡色区分；短文自然撑宽，时间右下，不因固定回复行变成竖长卡。长文/媒体优先可读，真实已读信息缺失时不添加假勾。

## 6. 检查与维护

- 先核对已有规范/组件：符合的保留，只补缺口。字体、材质、字号与结构有冲突时列来源，确认后同步，不绕开主组件另建主题。
- 用相关页面实际截图验证：中文不截断，输入/关闭/发送可达，深浅字与状态清楚，当前背景未变；键盘焦点、上下文及业务结果按收尾方案第十节验证。
- 修改共享材质才检查全部受影响页面；单个组件只检查相关页面。不把原型、设计截图或文档检查当作代码/业务通过。
- 本文件是本地长期规范入口；任务方案记录范围和例外。修改需用户确认，并同步相关Figma Variables/Styles/Components，避免两套参数独立漂移。
