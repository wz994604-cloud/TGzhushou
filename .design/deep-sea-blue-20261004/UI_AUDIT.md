# UI Audit

- 角色：管理员；首要任务是切换机器人、查看会话、编写和发布活动。
- 当前问题：整体已有工作台结构，但深色侧栏、顶栏和内容区 token 不统一；聊天空态与已选聊天的背景职责不清；普通页面需要更稳定的浅蓝灰表面。
- 目标层级：深海蓝导航 > 白色顶栏 > 浅蓝灰页面底 > 白色卡片/表格 > 蓝色主操作。
- 状态：保留现有 loading/error/empty 状态；仅增强 chat 未选空态和已选会话背景，不制造消息或统计。
- 移动端：沿用现有单栏/抽屉行为，只调整颜色和空态间距。
- 风险：不改业务数据、权限、外链、批量发送、Token 或 API 请求。
